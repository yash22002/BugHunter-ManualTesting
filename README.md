# BugHunter-ManualTesting 🐞

A manual testing practice repository containing test cases for web application features.

## 📌 Project Overview

This repository contains manually designed test cases created to practice software testing concepts and improve QA testing skills.

The test cases focus on checking application functionality, input validation, user behavior, and possible negative scenarios.

## 📂 Module Covered

### Login Page

The Login Page test cases cover:

- Valid username and password
- Invalid username and password
- Blank username field
- Blank password field
- Blank username and password fields
- Minimum username length validation
- Maximum username length validation
- Username length below the minimum limit
- Username length above the maximum limit
- Password visibility functionality
- Login button functionality

## 🧪 Testing Types Covered

- Positive Testing
- Negative Testing
- Functional Testing
- Boundary Value Testing
- Validation Testing
- UI Testing

## 📊 Test Case Details

Each test case contains the following details:

- Test Case ID
- Test Case Description
- Precondition
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Status
- Comments
